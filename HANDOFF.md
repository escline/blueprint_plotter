## Architecture

```
model file ──load_raw──▶ trimesh mesh ──orient──▶ Z-up mm mesh
   │
   └─ per view (camera.py): hlr.compute_view ─▶ ViewLines (visible/hidden segments, view mm)
                                   │
              sheet.plan_layout / draw_view / frame_lines / compose
                                   │
          ┌────────────────────────┴───────────────────────────┐
   CLI/export: output.build_document (vpype)          UI preview: server /api/compose
   ─▶ layered, path-optimised SVG                     ─▶ per-view geometry, view-local coords
```

### Python package `blueprint/`

| File | Role |
|---|---|
| `loader.py` | `load_raw` (clean mesh, fix winding), `orient` (up axis, rotation steps, units, centre), `load_mesh` (both, for CLI) |
| `camera.py` | Orthographic cameras. Model is **Z-up, front faces -Y**. Names: front back left right top bottom iso |
| `raster.py` | numba z-buffer rasteriser (`rasterize_depth`). Falls back to slow pure Python without numba |
| `hlr.py` | Edge selection + hidden-line removal. Returns `ViewLines` |
| `sheet.py` | Layout, scale choice, dimensions, border, title block, dashing. Y-up mm, origin bottom-left |
| `text.py` | Single-stroke Hershey lettering (font `futural`) |
| `output.py` | vpype Document build, merge, simplify, sort; `svg_string`, `stats_dict`, `merge_segments` |
| `server.py` | FastAPI app: upload, compose preview, export, samples, static UI |
| `cli.py` | `render` (default), `plot`, `serve` subcommands |
| `plot.py` | Thin `nextdraw` wrapper, `axicli` fallback (preview-tested only) |
| `web/static/` | **Built** front end (generated by `npm run build`) |
| `web/samples/` | Three sample STLs served by the UI |

## Key design decisions (and why)

1. **SVG is the interchange format; layers are pens.** Layer 1 = visible outlines, 2 = hidden (dashed), 3 = dimensions/text/border/title. AxiDraw layer mode keys on layer names starting with a number, which vpype writes as `inkscape:label="1"`.
2. **Mesh-based HLR with a depth buffer**, not exact B-rep. Needed because online STLs are the main input. Candidate edges are creases (> `--angle`), silhouettes and open boundaries; each edge is cut into ~3 px pieces and depth-tested against the buffer.
3. **Layout is client-side in the UI.** `/api/compose` returns each view's strokes **relative to the view's own centre**, plus `box` (extent including dimensions) for hit-testing. Dragging never round-trips. Scale/orientation/paper/linework changes do. Placements are *not* sent to compose; they are sent only to export.
4. **`placements == null` means automatic layout.** Cleared when model, orientation or paper changes. Dragging a view first snapshots all current centres.
5. **Hidden lines are dashed at export only.** The preview dashes them natively on canvas (`result.dash`).
6. **Hershey stroke font** for all text, because outline fonts plot badly.
7. **vpype does path work.** Strokes are merged with `LineCollection.merge`, then `linesimplify` + `linesort` on the document.
8. **Server is single-user and local.** Binds 127.0.0.1, keeps the last 8 models in memory, 300 MB upload cap. No auth, no persistence.

## API contract (`server.py`)

- `POST /api/models` (multipart `file`) -> `{id, name, triangles, extents}`
- `GET /api/samples`, `POST /api/samples/{name}` -> same shape as upload
- `POST /api/compose` (JSON `SheetRequest`) -> `page, scale, scale_label, fit_scale, fit_label, overflow, extents, dash, frame, views{name:{center,size,box,extents,visible,hidden,notes}}, layers{1,2,3:{strokes,length_mm}}`
- `POST /api/export` (same request, `placements` honoured) -> SVG body, `Content-Disposition`, and `X-Blueprint-Stats` JSON header
- `SheetRequest`: `model_id, orientation{up, steps[[axis,deg]...], model_scale}, views[], angle, resolution, hidden, hidden_silhouettes, dims, page, margin, title, scale, placements`

Caches are `lru_cache`d per (model, orientation, view, angle, resolution, flags) and cleared whenever a new model is stored.

## Gotchas learned the hard way

Read these before touching `hlr.py` or `sheet.py`.

- **Faces exactly edge-on to the camera (dot == 0)** are common in CAD exports and symmetric meshes. Silhouettes are found by `front[a] != front[b]` with `front = n·d < -1e-9`. The earlier `da*db < 0` test silently dropped outline segments. There is a regression test.
- **Smooth silhouettes need a forgiving depth test.** Depth falls away steeply at a curved outline, so a strict test marks real outlines "hidden". Smooth silhouettes use a 3x3 *max* filter of the depth buffer; creases and boundaries use the strict test.
- **Coincident edges must be collapsed before the visibility test.** Top and bottom rims of a through-hole project onto the same line and are both truly visible. Edges are quantised at `0.1*pix` endpoints and only the nearest is kept. This cut the plate's top view from 440 polylines to 6.
- **End-on edges project to a point** and would plot as dots. Edges shorter than `0.25*pix` are dropped.
- **Hidden pieces under visible strokes are removed** with a dilated mask so dashes never overpaint solid lines.
- **Hidden outlines of curved surfaces** (`--no-hidden-silhouettes`) are right for bores/holes but noise on organic meshes; it is a user toggle rather than guessed.
- **Dimensions on narrow spans** flip arrows outside and move text beside them (`_dim_axis`). Don't revert to the single-layout version.
- **Hershey API:** pip package is `Hershey-Fonts`, import `HersheyFonts`. With `normalize_rendering(size)`, cap height is `0.75*size` and the baseline offset `0.25*size`; y is up.
- **vpype units are CSS px** (96 dpi). `output.py` converts mm via `vp.convert_length("1mm")` and flips y (SVG is y-down, internal sheet space is y-up). `merge_segments` works in plain units with no flip.
- **numba compiles on first use** (a few seconds; `cache=True` helps). The first compose after a fresh start is slow; don't mistake it for a hang.
- **React number inputs:** pass numbers, not formatted strings, or typing `12.` gets clobbered to `12`.
- **Canvas drawing uses cached `Path2D` per view in view-local mm** with `ctx.setTransform` for placement. Line width is clamped to ~0.8 px so nothing disappears when zoomed out.
- **Compose is debounced 150 ms** and aborts in-flight requests, but the server cannot cancel work already started. Slider-style controls commit on release for that reason.
- **AxiDraw model numbers:** 2 = V3/SE A3 (the default here). A3 travel is slightly larger than the sheet; the default border is inset 10 mm.

## Commands

```bash
pip install -e ".[web,dev]"        # add ,step for .step/.stp
pytest -q                          # 18 tests (core + API)
python tests/make_samples.py       # regenerate samples/*.stl

cd web
npm install
npm test                           # 9 geometry tests
npm run dev                        # Vite dev server; proxies /api to 127.0.0.1:8765
npm run build                      # writes into blueprint/web/static

blueprint serve                    # UI on :8765
blueprint part.stl --title X --scale 1:2
blueprint plot part.svg --preview  # needs nextdraw (or axicli); never run on hardware yet
```

For front-end work run `blueprint serve --no-browser` in one terminal and `npm run dev` in another.
